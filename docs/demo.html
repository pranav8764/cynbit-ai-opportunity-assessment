Cross-review issue mining - interactive demo

Proof of concept for the Cynbit AI/ML Engineer Intern assessment. An LLM extracts structured aspects (category, sentiment, severity, verbatim evidence) from free-text reviews; plain analytics then rank each branch's top issues by frequency x severity. Code and reports: github.com/pranav8764/cynbit-ai-opportunity-assessment

1. Analyze your own review

Live analysis calls the hardcoded OpenRouter free model nvidia/nemotron-3.5-super-vl:free from your browser using your own OpenRouter key (free keys are available at openrouter.ai). The key is used only for this page's requests and is never stored or sent anywhere else. Input capped at 2000 characters; at most 8 live analyses per page load.

2. Run the 15-review sample batch

Canned replay (default) instantly replays saved model responses through the same analytics pipeline - it proves the pipeline, not the model. Live batch sends all 15 synthetic reviews from the repo to the free model one by one (about a minute) and needs your key above; at most 2 live batches per page load.
